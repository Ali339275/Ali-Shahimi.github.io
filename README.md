# Ali Shahimi — personal biography

Open `dist/index.html` in a browser. No build or JavaScript is required.

- Edit biography, timeline and contact links in `dist/index.html`.
- Replace `dist/assets/portrait.png` to change your portrait. Adjust `.portrait img` in `dist/style.css` to change cropping.
- Edit colors and layout in `dist/style.css`.
- The supplied CV is included in assets as a reference. It is not linked on the page because its student status predates the updates on this site.
- Project dates were not supplied in the CV, so undated projects appear as a list below the dated academic/research timeline.
- Fonts load from Google Fonts, with local fallbacks when offline.
